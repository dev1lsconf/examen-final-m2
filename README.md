# Registro de libros

Aplicación PHP con MySQL para añadir libros a la base de datos `llibreria`.

## Preparación

1. Importa `database.sql` en MySQL.
2. Configura host, usuario, contraseña y base de datos en `config.php`.
3. Sirve esta carpeta con un servidor PHP que tenga habilitada la extensión MySQLi.
4. Abre `index.php` en el navegador y registra un libro.

La tabla `libros` genera `idLlibre` automáticamente; el formulario no lo solicita.
No subas a GitHub contraseñas ni datos reales del ISP. `datos_isp.txt` contiene
solo campos vacíos para completar localmente.
